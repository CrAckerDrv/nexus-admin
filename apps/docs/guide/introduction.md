# 项目介绍

**Nexus Admin** 是一套面向中后台场景的**通用模板**：模块化架构 + 自研零依赖组件库 + 可跑通的演示数据。

它解决的核心问题不是"再做一个 UI 库"，而是**让新增一个业务模块的成本降到最低**——从改路由、改菜单、改权限校验，变成写一个声明式清单。

## 为什么是"模板"而不是"框架"

|          | 重型后台框架        | Nexus Admin                   |
| -------- | ------------------- | ----------------------------- |
| 引入方式 | 全量安装依赖        | 复制代码，按需删改            |
| 组件样式 | 需要覆盖主题变量    | 设计令牌直接改 CSS 变量       |
| 模块扩展 | 约定目录 + 插件协议 | 一个 `module.ts` 对象         |
| 包体积   | 常见 400KB+ gzip    | 首页 ≈ 120KB gzip（不含图表） |
| 学习成本 | 框架专属概念多      | 只有 React + Tailwind 知识    |

## 技术选型

| 层   | 选择               | 理由                                                                |
| ---- | ------------------ | ------------------------------------------------------------------- |
| 框架 | React 19           | `useSyncExternalStore`、`useDeferredValue` 等新原语，避免额外状态库 |
| 构建 | Vite 8（Rolldown） | 冷启动 < 500ms，产物分析更细                                        |
| 路由 | TanStack Router    | 全类型安全 + 内置预加载 + 懒加载路由组件                            |
| 数据 | TanStack Query 5   | 缓存、重试、失效策略开箱即用                                        |
| 样式 | Tailwind CSS v4    | CSS-first 配置，`@theme` 直接映射设计令牌                           |
| 状态 | Zustand 5          | 仅用于跨页面的 UI 偏好与登录态，业务数据走 Query                    |
| 图表 | ECharts 6          | 按需注册 + 动态加载，中文生态最完整                                 |

## 设计原则

1. **零黑盒**：所有组件源码都在仓库里，改样式不需要和第三方库打架
2. **声明优于配置**：导航、路由、权限是同一份数据的三个视图
3. **可删除性**：任何一个模块目录删掉，其余部分仍可运行
4. **渐进接管**：Mock 层与真实接口共存，可以一个接口一个接口地切换

## 目录速览

```
apps/admin    后台应用（模块化业务）
apps/docs     文档站（VitePress）

```
